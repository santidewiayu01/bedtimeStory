# Placeholder model folder (no longer used by the Hero)

The Hero section was migrated from a full 3D camera journey (Three.js /
React Three Fiber) to a 2.5D layered-illustration scroll experience —
see `src/components/immersive/HeroParallaxScene.jsx` and
`src/components/immersive/HeroLayers.jsx`.

`.glb` / `.gltf` models are no longer part of the Hero. This folder is
kept only in case a future 3D feature elsewhere on the site needs it.

For Hero illustration assets (background, decoration, focal
character), see `public/assets/README.md` instead.
